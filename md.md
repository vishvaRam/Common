
**Headline:** 🐍 Search YouTube in Python. No API Key. Async.

I got tired of managing API quotas just to find video IDs for my RAG pipelines, so I built `py-youtube-search`.

It’s lightweight, works with `aiohttp`, and has built-in filters for finding long-form content (perfect for tutorials).

✅ **Async & Fast**
✅ **No Google Cloud Setup**
✅ **Duration & Date Filters**

**Install:**
`pip install py-youtube-search`

**Links:**
